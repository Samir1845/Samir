DOM Explorer | JavaScript Fundamentals

Exploring how JavaScript interacts with HTML.

A beginner JavaScript project focused on understanding DOM selection, accessing HTML elements, working with variables, and displaying dynamic content on a webpage.

Overview

DOM Explorer is a small practical experiment designed to explore the connection between HTML and JavaScript.

It demonstrates how JavaScript can identify specific HTML elements using different selection methods, retrieve their text content, and display values directly in the browser.

Features & Concepts

Concept| Description
"getElementById()"| Select elements using their ID
"getElementsByClassName()"| Access elements through class names
"getElementsByTagName()"| Select elements using HTML tags
"innerText"| Retrieve element text content
"document.write()"| Display output dynamically
Variables| Understand "let" and "var"
Arithmetic| Perform basic mathematical operations
Concatenation| Combine strings and values

Live Code Demonstration

The project explores examples such as:

let a = 20;

let rollno = 101;

document.write("Roll No. " + rollno);

document.write(10 + 5);

document.write("10" + "5");

Understanding the output:

- "10 + 5" produces "15".
- ""10" + "5"" produces "105".
